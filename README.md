## How can i Use it

### Clone Project
```bash
git clone https://github.com/ahmadsiddique-dev/gsap
```

### Change Directory
```bash
cd gsap
```

### Install Dependencies
```bash
npm install
```

After installation youneed to run it

### Run Project
```bash
npm run dev
```

Now in browser navigate to 

```bash
http://localhost:5173

```

ther you will see the project
